# KalaYar (کالایار) 📦
### Modern Inventory Management and Smart Store Management App

**KalaYar** is a powerful and user-friendly solution for managing product inventory, recording financial transactions, and accurately analyzing store performance. This app is designed to simplify complex inventory processes for small and medium business owners.

## 🌟 Key Features

### 📋 Smart Inventory Management
*   Register and edit products with full details (name, unit, buy/sell price).
*   Fast search among a large number of goods.
*   Real-time view of stock count and inventory status.

### 💰 Transaction & Invoice System
*   Record incoming (stock increase) and outgoing (sale) transactions.
*   Ability to add custom descriptions and titles for each transaction.
*   **PDF Invoice Export:** Quickly generate and share professional invoices with your store information.

### 📊 Advanced Reports & Analytics
*   **Sales Report:** View sales over different time ranges (today, last 1 month, 3 months, 6 months, and last 1 year).
*   **Inventory Value:** Automatic calculation of total inventory value based on registered prices.
*   **Product Stats:** See total product count and variety at a glance.

### 📈 Live Prices (Updated from Tasnim)
*   Real-time display of gold, coin, and common currency prices (Dollar, Euro, Pound, etc.) for better cost management.

### 🔒 Security & Personalization
*   Ability to set a password for app login.
*   Support for **Dark Mode** for eye comfort in low-light environments.
*   Contact and customer management for more accurate invoicing.

### 💾 Backup & Restore
*   Backup your database and restore it to prevent data loss.

## 🛠 Technologies Used

KalaYar is developed with the latest Android tools and libraries:

*   **Language:** Kotlin & Java
*   **Architecture:** MVVM (Model-View-ViewModel)
*   **Database:** Room Database (for fast offline storage)
*   **Networking:** Retrofit & Gson (for live prices)
*   **UI:** Data Binding, ViewModels, Navigation Component
*   **Date Support:** PrimeCalendar (for Jalali and Gregorian calendars)
*   **Design:** Material Design 3
